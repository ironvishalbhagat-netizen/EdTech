# EdTech
AI-powered personalized EdTech learning platform
EdTech is a web-based learning platform designed to make education easier and more interactive for students and teachers.
The main aim of this project is to provide a common platform where teachers can manage their classes and students can access learning materials easily.
Teachers can create batches, share notes, upload assignments and provide recorded lectures.
Students can join batches using a unique code and access their study materials, assignments and lectures.
The platform also includes attendance management, notifications and calendar features to make learning more organized.
An AI-based feature helps students get personalized learning roadmaps according to their learning needs.
Our goal is to reduce the gap between teachers and students through a simple and user-friendly platform.
Technologies Used
The project is developed using modern web technologies, including HTML, CSS, JavaScript, Node.js, Express.js and MongoDB.
AI integration is also used to improve the overall learning experience.
